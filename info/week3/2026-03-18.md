#### `app/src/lib/ConsentManager.ts`
Cœur de la logique RGPD. Gère uniquement les cookies JS-accessibles (jamais les httpOnly).

**Utilitaires cookie :**
| Fonction | Rôle |
|---|---|
| `setCookie(name, value, days?)` | Écrit un cookie, URI-encodé, SameSite=Lax |
| `getCookie(name)` | Lit un cookie par nom → `string \| null` |
| `deleteCookie(name)` | Supprime un cookie (expire dans le passé) |

**Fonctions principales :**
| Fonction | Rôle |
|---|---|
| `getConsents()` | Lit et parse `omm_cookie_consent` → `ConsentData \| null` |
| `saveConsents(choices)` | Sauvegarde + applique immédiatement les effets |
| `initConsents()` | Appelé au chargement de l'app — ré-applique les effets des consentements déjà stockés |
| `shouldShowBanner()` | `true` si première visite ou version de politique changée |
| `revokeAll()` | Supprime tous les cookies optionnels + sauvegarde un refus complet |

**Logique de déclenchement conditionnel (`applyConsentSideEffects`) :**
| Consentement | Effet |
|---|---|
| `marketing: true` | Set `newsletter_consent` (14 jours) + appel `initBrevo()` |
| `marketing: false` | Supprime `newsletter_consent` (Brevo non chargé) |
| `functional: true` | `pickup_slot_pref` pourra être écrit plus tard par la logique de créneau |
| `functional: false` | Supprime `pickup_slot_pref` immédiatement |

**Versionnement :**
`CONSENT_VERSION = '1.0'` — changer cette valeur force la réaffichage de la bannière pour tous les utilisateurs existants.

**Brevo (stub prêt) :**
`initBrevo()` est implémenté mais en commentaire. Pour activer : ajouter `VITE_BREVO_CLIENT_KEY=xxx` dans `app/.env` et décommenter les 4 lignes dans la fonction.

#### `app/src/hooks/useConsent.ts`
Hook React qui expose le ConsentManager aux composants.

```typescript
const { consents, updateConsents } = useConsent();
```

- `consents` — état React (`ConsentData | null`) — `null` si l'utilisateur n'a jamais consenti
- `updateConsents(choices)` — sauvegarde + applique + sync backend silencieuse

**Sync backend :**
Appelle automatiquement `PATCH /api/users/me/consents` si l'utilisateur est connecté (`auth_token` cookie présent). Les erreurs 401 (non connecté) et les erreurs réseau sont ignorées silencieusement — les visiteurs peuvent aussi accepter les cookies sans compte.

### Comment tester

#### Option 1 — Test dans le navigateur (rapide)
1. `cd app && npm run dev`
2. Ouvre `http://localhost:5173`
3. Ouvre DevTools → **Application** → **Cookies** → `localhost`
4. Dans la console DevTools, colle :

```javascript
// Importer depuis le module ES (fonctionne avec Vite)
// Coller dans la console après chargement de la page

// Tester shouldShowBanner (doit être true au premier lancement)
// Tester saveConsents
// Tester revokeAll
// Observer les cookies apparaître/disparaître dans l'onglet Application
```

> Note : les modules ES ne sont pas directement appelables depuis la console. Utilise l'Option 2.

#### Option 2 — Remettre temporairement le composant de test
Remplace le contenu de `App.tsx` par le composant `ConsentTest` utilisé précédemment, lance `npm run dev`, teste les boutons, puis remets `App.tsx` dans son état actuel.

#### Option 3 — Tester via `useConsent` dans un composant React
Crée un composant temporaire qui utilise le hook :
```tsx
import { useConsent } from './hooks/useConsent';

function Test() {
  const { consents, updateConsents } = useConsent();
  return (
    <div>
      <pre>{JSON.stringify(consents, null, 2)}</pre>
      <button onClick={() => updateConsents({ marketing: true, functional: true })}>
        Tout accepter
      </button>
    </div>
  );
}
```

#### Ce qu'il faut vérifier dans tous les cas
| Action | Cookie attendu |
|---|---|
| `saveConsents({ marketing: true, functional: true })` | `omm_cookie_consent` + `newsletter_consent` présents |
| `saveConsents({ marketing: false, functional: true })` | `newsletter_consent` absent |
| `saveConsents({ marketing: false, functional: false })` | `newsletter_consent` + `pickup_slot_pref` absents |
| `revokeAll()` | Tous les cookies optionnels supprimés |
| Recharger la page après acceptation | `initConsents()` ré-applique les effets (Brevo re-init si marketing) |
| `shouldShowBanner()` avant tout | `true` |
| `shouldShowBanner()` après `saveConsents` | `false` |
