## Règles respectées

- `passwordHash` jamais retourné — supprimé par le `toJSON` transform du schéma Mongoose
- JWT extrait uniquement du cookie httpOnly `auth_token`, jamais d'un header Authorization
- bcrypt 10 rounds
- `cookieConsents.date` défini côté serveur (non fourni par le client)
- L'inscription ne délivre pas de token
- `ConflictException` si email déjà utilisé (message en français)
- Login : même message d'erreur pour email inconnu et mauvais mot de passe (pas d'énumération)
- Cookie `auth_token` : `httpOnly`, `sameSite: lax`, `secure` en production uniquement, `maxAge` 1 jour

## Résultat des tests

```
POST /api/auth/register               →  201 + objet user (sans passwordHash)
POST /api/auth/register               →  409 si email déjà existant
POST /api/auth/login (correct)        →  200 + user + cookie auth_token posé
POST /api/auth/login (mauvais mdp)    →  401 "Email ou mot de passe incorrect."
GET  /api/users/me (avec cookie)      →  200 + profil utilisateur complet
GET  /api/users/me (sans cookie)      →  401
```
